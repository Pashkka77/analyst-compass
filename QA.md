# Самопроверка сравнительного формата — 23 октября 2026

Фидбэк: трудно отвечать на шкалу «привлекает / не привлекает», поскольку человеку могут нравиться все задачи или не нравиться идея работы вообще. Формат заменён на 12 сравнений двух конкретных задач. Таблица перечитана; исправлены устаревшие шкалы, описание методики, персональные объяснения и баланс позиции вариантов.

| Проверка | Результат |
|---|---|
| Формат | В основных вопросах нет шкалы согласия; предлагаются две конкретные задачи |
| Баланс ролей | Каждая роль появляется 6 раз; каждая из 6 пар — дважды |
| Баланс позиции | Каждая роль 3 раза в А и 3 раза в Б; выбор всегда первого варианта сам по себе не назначает роль |
| Расчёт | Выбор = 1; равный выбор = по 0,5; пропуск исключён; нормализация на 6 |
| Четыре профиля | Последовательное предпочтение каждой роли даёт её как основной результат — Node |
| Шесть пар и адаптация | Обе стороны каждой пары, остановка на 14/15 вопросах, второе близкое направление — Node |

| Описания профессий | Сохранены, раскрываются отдельно от главного итога |
| Публикация | Проверяется после одного общего коммита; окончательный статус — в чате |

Это авторский опрос предпочтений, не научно валидированный тест. Результат — гипотеза для практической пробы. На физических мобильных устройствах и со скринридером отдельно не проверялся. Изменение формата следует повторно дать реальным пользователям: внутренние проверки не доказывают рост вовлечённости или точности.

# Какой ты аналитик? ↗

Статический сайт для GitHub Pages: 20 авторских вопросов, четыре направления, прозрачный расчёт и мини-задачи для первой пробы.

## Запуск

Откройте `index.html` или выполните `python -m http.server 8765` и перейдите на http://localhost:8765. Сборка и зависимости не нужны.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. Страница будет доступна по адресу https://pashkka77.github.io/analyst-compass/ после успешного развёртывания. Этот адрес — ожидаемый, факт публикации проверяется отдельно.

## Методика

Пять вопросов на каждое направление: бизнес-анализ, системный анализ, анализ данных, продуктовая аналитика. Шкала интереса 0–3. Ответ «Пока не понимаю задачу» исключается. Для интерпретации нужно не менее трёх содержательных ответов на каждое направление. При пропусках среднее умножается на 5; максимум 15. Разрыв до двух баллов считается близким интересом. Максимум менее 7,5 трактуется как отсутствие устойчивого интереса. Границы авторские, эмпирически не валидированы. Это опрос интересов, не тест способностей и не прогноз карьеры.

Направления пересекаются; продуктовая аналитика является специализацией работы с данными. Финансовая, маркетинговая и другие специализации в эту версию не входят. Ответы не отправляются на сервер, контакты не собираются; нет внешних шрифтов, библиотек и счётчиков. После обновления страницы ответы сбрасываются.

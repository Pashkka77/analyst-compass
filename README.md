# Какой ты аналитик? ↗

Статический сайт для GitHub Pages: 12–15 вопросов с адаптивными уточнениями, четыре направления, прозрачный расчёт и мини-задачи для первой пробы.

## Запуск

Откройте `index.html` или выполните `python -m http.server 8765` и перейдите на http://localhost:8765. Сборка и зависимости не нужны.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. Страница будет доступна по адресу https://pashkka77.github.io/analyst-compass/ после успешного развёртывания. Этот адрес — ожидаемый, факт публикации проверяется отдельно.

## Методика: сравнительный выбор

12 коротких ситуаций, в каждой две задачи из разных направлений. Вопросов «тебя это привлекает?» и шкалы согласия больше нет. Нужно выбрать более близкую лично задачу. Все 6 пар профессий встречаются дважды. Каждая роль участвует в 6 сравнениях, 3 раза в позиции А и 3 раза в Б. Есть равный выбор и пропуск.

Выбор задачи даёт её роли 1 балл, равный выбор — по 0,5 обоим. Пропуск исключается. При пропусках среднее по отвеченным сравнениям роли умножается на 6. Для вывода нужны минимум 8 ответов с выбором или равенством и минимум 3 отвеченных сравнения на каждую роль. Баллы отражают относительное предпочтение среди предложенных задач; абсолютный интерес, профессиональные навыки и пригодность они не измеряют.

Если отставание от лидера не превышает 1 балл, роли включаются в адаптивные уточнения. При одном кандидате результат после вопроса 12. При нескольких — 2 уточнения; два одинаковых выбора заканчивают тест на 14 вопросах, иначе добавляется 15-й. Единственный итог требует минимум 2 голосов уточнений и больше голосов, чем у остальных. Равный интерес и отсутствие выбора голосов не дают. Если предпочтение не выявлено, остаётся смешанный профиль. Основные баллы и уточнения показываются отдельно.

Персональные объяснения содержат задачи, которые человек действительно выбрал. Подробные описания профессий сохранены. Вопросы не проверяют знания или желание работать вообще. Формат и пороги авторские, без научной валидации; рост точности после изменения не заявляется. Ответы хранятся только в памяти браузера, сторонних счётчиков нет.

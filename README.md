# Какой ты аналитик? ↗

Статический сайт для GitHub Pages: 12–15 вопросов с адаптивными уточнениями, четыре направления, прозрачный расчёт и мини-задачи для первой пробы.

## Запуск

Откройте `index.html` или выполните `python -m http.server 8765` и перейдите на http://localhost:8765. Сборка и зависимости не нужны.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. Страница будет доступна по адресу https://pashkka77.github.io/analyst-compass/ после успешного развёртывания. Этот адрес — ожидаемый, факт публикации проверяется отдельно.

## Методика

12 базовых вопросов и до 3 адаптивных уточнений. База: 3 вопроса на направление, 0–3 за ответ, максимум 9. Пропуск исключается, нужно минимум 2 ответа на каждое направление. При пропусках используется среднее × 3. При максимуме ниже 4,5 нет назначения профессии.

Кандидаты для уточнений: минимум 4,5 и отставание от базового лидера не более 1,5 балла. При одном кандидате — результат сразу. При двух и более — выбор личных задач из одного рабочего контекста. Два одинаковых выбора завершают тест после вопроса 14, иначе задаётся вопрос 15. Для главного результата нужны минимум два выбора и строго больше голосов, чем у остальных. Равный интерес и отсутствие выбора не дают голосов. При отсутствии устойчивого предпочтения показывается смешанный профиль. Уточнения не прибавляются к базовой шкале. Порядок вариантов меняется между уточнениями.

Персональное объяснение строится из положительных базовых ответов и выбранных задач уточнений. Первым показан основной результат, затем практическая проба и соседнее направление. Баллы и подробности четырёх профессий раскрываются отдельно.

Это авторская эвристика интересов, не психометрическая диагностика и не проверка профессиональных навыков. Пороговые значения не валидированы. Ответы хранятся только в памяти браузера. Нет библиотек, внешних шрифтов и счётчиков.
